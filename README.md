# Seblak Prasmanan Simulator (2.5D Mobile)

## Cara Build APK Otomatis via GitHub Actions:
1. Upload seluruh isi folder ini ke repository GitHub baru Anda.
2. Buka tab **Actions** di repository GitHub Anda.
3. Klik workflow **Build Seblak Prasmanan APK** dan tunggu hingga selesai (centang hijau).
4. Unduh file APK di bagian **Artifacts** paling bawah halaman workflow.
